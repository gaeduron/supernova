# Supernova

Simple link-in-bio page for **@nicolas_jaffre** — Instagram, Twitter, and Twitch.

## Development

Requires Node.js 22+.

```bash
npm install
npm run dev
```

Open [http://localhost:4321/](http://localhost:4321/) after `npm run dev`.

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `master` deploy automatically via GitHub Actions.

1. In the repo: **Settings → Pages → Build and deployment → Source** → **GitHub Actions**
2. Push to `master`

Live site URL depends on your GitHub Pages setup (custom domain or `gaeduron.github.io` user site with `base: '/'`).
